直接使用当前本机 OCR 引擎对「已审核 + 测试集」的文字框进行裁剪推理，统计字符错误率（CER）、精确匹配率和平均推理耗时。一次最多评估 5 张图片、40 个文字区域；不会修改标注、训练模型或上传图片。没有正确标注时请先在上方人工审核并将图片划为测试集。

批量汇总只在当前页面临时计算。可以导出含测试集版本指纹、总计和错误区域索引的 JSON 报告，**不包含原始文字、预测文字或图片**。停止、超限或失败时会标注为部分报告。
