# LocalOCR 开发路线（2026-11-22 更新）

## v0.1：独立识别引擎与本地 API

- [x] Python 包、CLI、Tesseract 实际图像 OCR、RapidOCR 3.x 格式适配层。
- [x] 统一 OCR 输出文本、坐标框、置信度、耗时。
- [x] 本地鉴权 HTTP API 和图像格式/尺寸校验。
- [x] RapidOCR / ONNX Runtime 真模型加载和推理：Linux 英文、Windows 中英文合成图片通过 GitHub Actions；尚缺独立固定测试集的准确率评估。
- [ ] Windows RapidOCR 完全离线启动与独立 EXE 真机验收。

## v0.2：可视化样本标注与审核准备（本次）

- [x] 无前端构建依赖的本地标注网页，`/studio` 与 `python -m localocr studio`。
- [x] 多图片导入、缩放预览、拖拽框选、OCR 建议、人工文本修正。
- [x] 图片去重、私有 SQLite 数据库、来源说明、修订号冲突处理。
- [x] 草稿和人工审核、train/val/test 标签、带图片与 JSONL 的 ZIP 导出。
- [x] 新增后端与协议自动化测试；后端进程级 API 验收。
- [ ] Windows Chrome/Edge 图形化真实点击验收（当前容器浏览器策略阻断）。

## v0.3：训练准备与评估

- [ ] 基于整张图划分训练/验证/测试集，支持固定随机种子和组级划分。
- [x] 兼容 PPOCRLabel / PaddleOCR 的文字检测（det）格式导出；识别（rec）裁剪集后续开发。
- [ ] 标注变更审计、批量审核、质量抽样与版本快照。
- [ ] 标准测试集的字错率 CER、行级精确匹配率与延迟评估。
- [ ] 数据备份和恢复、分页与更大规模样本列表、任务队列取消。

## v0.4：模型微调与桌面交付

- [ ] 接入经授权的 PaddleOCR 模型训练配置，明确 GPU、模型权重和许可证要求。
- [ ] 训练管理图形界面、进度展示、断点恢复、产物和模型版本管理。
- [ ] 在从未参与训练的测试集上报告准确率和速度；可以回滚。
- [ ] 正式 Windows EXE 打包及真实 Windows 10/11 验收。

现有界面是 **样本标注/训练准备工作台**，并不等于神经网络模型已经能在 UI 中执行训练。原私人仓库 `tk_tool` 的识别实现与样本库保持不变，也不包含对第三方服务在线验证码的验证或批量尝试。
